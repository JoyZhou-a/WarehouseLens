# SOP-ATP-2024 可承诺库存与订单承诺规范

版本：2024-06
适用范围：成品仓、备件仓

## 1. 可用库存口径

可用库存量按下式计算：

可用量 = 在库数量 - 已分配数量 - 已预留数量 - 质检扣留数量 + 已到在途数量

其中已分配指已生成发货单但未出库的占用，已预留指销售已锁定的占用，质检扣留指被质量部门冻结的数量，三者都不参与新单承诺。

## 2. 可承诺量

可承诺量 = 可用量 - 安全库存

安全库存由计划部门每季度更新，未配置时按 0 处理。

## 3. 调拨

当本地仓可承诺量不足以覆盖订单时，可以评估跨仓调拨。调拨是否可行必须同时满足：

1. 源仓可承诺量充足，且源仓无未关闭的质量异常
2. 调拨时效加上源仓出库时效不超过客户要求日期
3. 调拨后源仓可承诺量不得低于其安全库存

调拨时效参考：合肥到上海 1 天，深圳到上海 2 天，香港保税到上海 3 天且需先完成清关。

## 4. 承诺输出的要求

每一笔承诺必须给出：可用量、可承诺量、缺口数量、补充方案、以及计算过程中命中的规则编号。不允许只给结论。
