# SOP-EXPIRY 批次效期管理规范

版本：2024-03
适用范围：全部仓库，备件仓重点执行

## 1. 临期定义

距过期日期不足 30 天的批次，定义为临期批次。

## 2. 出库顺序

同一物料同一仓库内，按过期日期从近到远出库，即先进先出。不得跳过临期批次直接出库远期批次，除非临期批次已被质检冻结。

## 3. 临期批次的用途限制

临期批次不得用于新订单承诺，只能用于以下场景：

1. 客户明确接受临期货物并书面确认
2. 售后备件替换
3. 内部试验或样机

## 4. 在途批次

在途批次的效期在到仓时判定。若在途批次到仓后即为临期批次，仍按第 3 条执行，不得因为「已经发了货」就计入可承诺量。这一点在 2023 年的两起超承诺事件中被明确要求。
